# 🟣 tachyon-kotlin (+ kt-schema)

Verdict: thin adapter. DSL builder wraps Java `ServerBuilder`; `suspend` handlers run as coroutines on the **server's VT executor** via an internal `ServerExtension`; kotlinx-serialization JSON plugs into the same api SPIs. Java first, Kotlin adapts (AGENTS.md).

## 🚪 Entry points

`tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/TachyonServerFactory.kt`:
- `TachyonServer(port) { … }` — build **and start** `TachyonServerFactory#TachyonServer`.
- `buildServer { … }` — build only `TachyonServerFactory#buildServer`.

## 🏗️ DSL

- Domain factory facades retain explicit `@file:JvmName` alongside `@file:JvmSynthetic`: `AnnotationsFactory`, `Icons`, `PromptMessages`, `InputRequests`, `ResourceContentsFactory`, `ResourceLinks`, `TaskSnapshots`, `ToolAnnotationsFactory`. Kotlin functions keep their JVM owners while the facade classes are synthetic. [AnnotationsFactories.kt](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/domain/AnnotationsFactories.kt), [IconFactories.kt](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/domain/IconFactories.kt), [PromptFactories.kt](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/domain/PromptFactories.kt), [RequestFactories.kt](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/domain/RequestFactories.kt), [ResourceFactories.kt](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/domain/ResourceFactories.kt), [ResourceLinkFactories.kt](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/domain/ResourceLinkFactories.kt), [TaskSnapshotFactories.kt](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/domain/TaskSnapshotFactories.kt), [ToolAnnotationsFactories.kt](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/domain/ToolAnnotationsFactories.kt).
- Skills registration is an imported extension: [skills](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/SkillsExtensions.kt) on `TachyonServerBuilder` delegates to `withExtension`. [SkillsScope#registry](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/SkillsExtensions.kt) appends Java registries; [SkillsScope#applyTo](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/SkillsExtensions.kt) converts non-negative Kotlin `Duration` to whole milliseconds and delegates cache-scope validation and negotiation. Every call replaces settings including defaults; registries accumulate. `tachyon-extensions-skills` is optional in [tachyon-kotlin/pom.xml](../../tachyon-kotlin/pom.xml); consumers add it explicitly.
- Conflicting settings fail before builder mutation: [NetworkScope#applyTo](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/NetworkScope.kt) rejects `address` with `host`/`port`; [JsonScope#applyTo](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/JsonScope.kt) rejects `serde` with `serializer`/`deserializer`.
- `TachyonServerBuilder` receiver `TachyonServerBuilder`; `tool(...)` overloads `TachyonServerBuilder`, `TachyonServerBuilder#tool`, `resource` `TachyonServerBuilder#resource`, `prompt` `TachyonServerBuilder#prompt`, `resourceTemplate` `TachyonServerBuilder#resourceTemplate`, `promptCompletion` `TachyonServerBuilder#promptCompletion`, `resourceCompletion` `TachyonServerBuilder#resourceCompletion`, [TachyonServerBuilder#name](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/TachyonServerBuilder.kt), `extensions`, [TachyonServerBuilder#pipelineCustomizer](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/TachyonServerBuilder.kt).
- Core scopes live in `config/*Scope.kt`: `CapabilitiesScope`, `NetworkScope`, `SessionScope`, `RuntimeScope`, `ServerInfoScope`, `JsonScope`, `ObservabilityScope`, `PayloadCaptureScope`, `ToolScope`, `ResourceScope`, `ResourcesScope`, `PromptScope`, `TemplateScope`, `CompletionScope`, `ContentScope`, `FeatureScope`. `@TachyonDsl` marker `TachyonDsl.kt`. Optional skills/tasks configuration extensions share their files with their scopes: [SkillsScope](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/SkillsExtensions.kt), [TasksScope](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/TasksExtensions.kt).
- `SessionScope`: options are the opt-in — [SessionScope#enable](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/SessionScope.kt) turns sessions on with defaults; [TachyonServerBuilder#stateless](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/TachyonServerBuilder.kt) is the opt-out. `SessionScope#sessionIdGenerator` exists as a nullable property **and** a lambda overload whose request is non-null (`McpDispatcher` substitutes an empty request).
- Content DSL accepts raw bytes for image/audio blocks: [ContentScope#image](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/ContentScope.kt), [ContentScope#audio](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/ContentScope.kt). Base64 encoding belongs to the wire codecs.
- [IconBuilder#data](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/domain/StructuredFactoryBuilders.kt) is experimental: raw bytes require `mimeType`, exclude `src`, and delegate data-URI encoding to [Icon#of](../../tachyon-api/src/main/java/dev/tachyonmcp/api/server/domain/Icon.java).
- `ToolScope#tasks` = `TasksExtension.tasks(ctx)`. Handler-scoped member. Builder configuration uses the imported [tasks](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/TasksExtensions.kt) extension on `TachyonServerBuilder`, delegating to `withExtension`. Server side: `TachyonServer.tasks` extension property `TasksExtensions.kt` (`@file:JvmSynthetic`: Java uses `TasksExtension.tasks(server)`). `ToolScope#tasks` resolves once per call (`lazy(NONE)`). `tachyon-extensions-tasks` is `<optional>` in [tachyon-kotlin/pom.xml](../../tachyon-kotlin/pom.xml): all three touch `TasksExtension` lazily, so a server without the jar runs until first use. `requireTasksModule` (`TasksExtensions.kt`) wraps them: a `NoClassDefFoundError` from `dev/tachyonmcp/extensions/tasks/` ⇒ ISE naming the dependency (cause kept); any other missing class rethrown as is.
- `ToolScope` result helpers: `success`, `text`, `raw`, `empty`, `fail(msg|{content})`, `inputRequired`, `content { }` `ToolScope`.
- Result blocks: `EXACTLY_ONCE` — [ToolScope#content](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/ToolScope.kt), [ToolScope#fail](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/ToolScope.kt), [PromptScope#content](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/PromptScope.kt). [TachyonServerBuilder#typedTool](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/TachyonServerBuilder.kt): `schemaGenerator` runs twice in place (`AT_LEAST_ONCE`).
- Registration funnels through `KotlinFeatureRegistrar` `KotlinFeatureRegistrar`.
- Resource-template contents builders retain the handler scope: [TextResourceContentsBuilder#param](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/domain/TextResourceContentsBuilder.kt) and [BlobResourceContentsBuilder#param](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/domain/StructuredFactoryBuilders.kt) expose scalar parameters; their `sequence` methods delegate list parameters to [TemplateScope#sequence](../../tachyon-kotlin/src/main/kotlin/dev/tachyonmcp/kotlin/server/config/TemplateScope.kt). Both reject parameter access outside a template handler.
- Post-build registration on server: `registerTool/Resource/ResourceTemplate/Prompt/PromptCompletion/ResourceCompletion` extensions + reified typed `registerTool<In, Out>` `TachyonServer`, `TachyonServer`; impl `DefaultKotlinTachyonServer` `DefaultKotlinTachyonServer`.
- Domain factories `domain/*Factories.kt` (content, icons, annotations, resources, requests, structured builders, task snapshots). `TaskSnapshot(from) { }` `TaskSnapshotFactories.kt`: `TaskSnapshotBuilder` seeds from `from` and builds via `TaskSnapshot.Builder#next(from)` (revision + 1 unless set), exposes `kotlin.time.Instant`/`Duration` (internal `@OptIn(ExperimentalTime::class)`, callers need none), `requireNotNull` on required fields, delegates to Java `TaskSnapshot.builder()` for validation. Not a `Tasks.publish { }` extension: the Java `publish(Consumer)` member wins via SAM conversion, so a same-named receiver-lambda extension never resolves.
- 🪶 No `inline` in the DSL except `reified` generics — `typedTool<In, Out>` `TachyonServerBuilder#typedTool`, `registerTool<In, Out>` `TachyonServer#registerTool`, `Args#decode`, `JsonArray#valuesAs`, `ToolRequest#arguments`. Scope entries and type-named factories are plain `fun` with an `EXACTLY_ONCE` `callsInPlace` contract, so their builders' ctor/`build`/`applyTo`/`toConfig` stay plain `internal` (mangled `$tachyon_kotlin`, not published). One `@PublishedApi` survives: `toolDescriptorOf` `ToolDescriptorScope`, reached from the two reified registrars. See [`docs/architecture/guidance.md`](../../docs/architecture/guidance.md) *Kotlin adapter shape*.

## 🌀 Coroutines

`CoroutineRuntime` internal `ServerExtension` id `dev.tachyonmcp/kotlin-coroutines`, `AdvertiseMode.NEVER` `CoroutineRuntime`:
- `bootstrap`: `CoroutineScope(SupervisorJob + executor.asCoroutineDispatcher() + CoroutineName("tachyon-kotlin"))`.
- `future(name, block)`: launch → `CompletableFuture`; future cancel ⇒ job cancel; job fail ⇒ future fail `CoroutineRuntime#future`.
- `shutdown`: cancel scope, wait up to `shutdownGracePeriod` `CoroutineRuntime#shutdown`.
- `*FnFactory.kt` adapt suspend lambdas to Java async SAMs.

## 🧾 JSON

- `KxSerializationSerde(Json)` implements `PayloadSerde` `KxSerializationSerde`.
- `KotlinxJsonElementFactory` / `KotlinxJsonObjectFactory` (`JsonDocumentFactory` + `JsonSchemaFactory`) via ServiceLoader `tachyon-kotlin/src/main/resources/META-INF/services/`.
- `JsonInterop.kt`: `JsonElement.toJacksonNode()`, `JsonObject.toJsonSchema()`, `ToolDescriptor.Builder.schemas(...)`.
- kt-schema module: `KtSchemaReflectionFactory : JsonSchemaFactory<Class<*>>` (reflection-generated schema) + `ktSchemaGenerator(...)` helper `KtSchemaReflectionFactory#sourceType`, `helpers#ktSchemaGenerator`. Generator failure (e.g. Java record with `int`) ⇒ `Optional.empty()`, chain falls to core `JavaTypeSchemaFactory` (`KtSchemaReflectionFactory#toJsonSchema`). Core's `KtSchemaResourceFactory` reads build-time generated schemas instead → [[json-layer]].
